# Zwiggy - Premium Food Delivery Platform

Zwiggy is a modern, responsive, and visually stunning frontend web application for a food delivery service, inspired by platforms like Zomato and Swiggy. It features a premium light-themed UI/UX built entirely from scratch without relying on external CSS frameworks.

## 🚀 Features

- **Modern UI/UX:** Clean, vibrant, and appetizing design with glassmorphism effects, modern typography (Outfit & Inter), and smooth micro-animations.
- **Hero Inspiration Section:** A "What's on your mind?" horizontal scroll feature allowing users to quickly jump into categories like Biryani, Pizza, Burger, Noodles, and Drinks.
- **Dynamic Food Menu:** Browse through a rich catalog of 20+ items complete with high-quality imagery, preparation times, prices (in ₹), and ratings.
- **Dietary Filters:** Instantly filter out non-vegetarian items using the "Veg Only" toggle. All items clearly display the standard Indian Veg/Non-Veg dietary icons (Green/Red dots).
- **Real-time Shopping Cart:** A sleek sliding sidebar cart to manage your order, adjust quantities, and view real-time subtotal and delivery fee calculations.
- **Authentication Modals:** Beautifully designed Sign In and Sign Up flows integrated directly into the application using a glassmorphic overlay.

## 🛠️ Tech Stack

- **Frontend Framework:** React 18 (Initialized via Vite)
- **Styling:** Pure Vanilla CSS (Custom CSS Variables, Flexbox/Grid, Keyframe Animations)
- **Icons:** Lucide React

## 📦 Running Locally

1. Install the required dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173` to view the application.
